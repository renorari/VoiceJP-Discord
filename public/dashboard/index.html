VoiceJP

通話を、もっと使いやすく。

VoiceJP+ (ボイスジェーピー・プラス) にすると、文字起こしと読み上げが高精度なAIに切り替わります。

  • サーバーごとに、必要な分だけ
  • 無くなっても、無料の標準モードで使い続けられます
  • 購入できるのは「サーバー管理」権限を持つ人だけです

      使うエンジン

      VoiceJP+ を選んでいても、クレジットが無いときは標準 (無料) が使われます。Discordの /engine でも変更できます。

      VoiceJP+ の月額プランでは、毎月クレジットが付与されます。使い切れなかった分は翌月に繰り越されます。特典として、通話の録音と自動文字起こし (/record) も使えます。

      プランの変更は、次回の更新日から反映されます。解約や支払い方法の変更は「支払いの管理」から行えます。

      必要なときに、必要な分だけ追加できます。残高に期限はありません。

      VoiceJP+ の月額プランに加入すると、通話の録音と自動文字起こしが使えます。

      まだ録音がありません。通話に参加した状態で /record start を実行すると、録音と自動文字起こしが始まります。

      録音と文字起こしは、30日後に自動で削除されます。文字起こしには VoiceJP+ のクレジットを使います (無くなると標準の文字起こしに切り替わります)。
